# 创世纪战手游、功能机外传与跨作品支线核查

核查截止：2026-10-18。本文是作品目录与剧情候选研究，不修改主年表。中文名称属于编辑用名，不冒称全部已有官方中文译名；原名放在表格的元数据列。发行年份只用于区分产品，绝不是故事发生年份。

## 结论与采用原则

- 功能机外传确有《勇者之墓》《克罗》《克罗2》《浪天篇》；《创世纪战3》手机系列另分四集，第四集仍是电脑版第一篇章的收束，不是第二篇章。
- 《阿修罗计划》不只有原作改编。它的《宇宙传奇》、独立事件、短期故事及方舟外层构成新的分支叙事；商店现名《创世纪战手游：西风狂诗曲》仍是同一应用，不新增算一部独立产品。[开发者对整体改编及新故事的说明](https://www.gamemeca.com/view.php?gid=1742812)、[发行商当前商店页](https://play.google.com/store/apps/details?hl=ko&id=com.linegames.gm)。
- 宇宙系统内的历史模拟、分支自身的方舟现实、旧电脑版历史必须分层。原作者明确解释其模拟框架；二季采访又明确说明救回乔安的独立冒险。不可把模拟某年、商店更新时间或回合计数混入旧作年历。[第一周年采访](https://www.khgames.co.kr/news/articleView.html?idxno=234703)、[第二点五周年采访](https://guildwars2.gameshot.net/common/con_view.php?code=GA6a3088260ba17)。
- 《安塔利亚战争》的玩家自编故事是用户创作，不是发行商新增正史。主线、开发者角色支线与玩家自编必须分开标记。[开发团队直接解释自编工具](https://www.gamemeca.com/view.php?gid=1499035)。
- 本轮没有找到本系列正式作品名为“迷失之魂”“遗失的萨迦”或“失落传奇”的原厂记录。检索对应英文与韩文后，命中主要是无关格斗网游及玩家希望该网游加入系列角色的提案，不能列为已发行外传。

## 四、已核实的相对关系与候选交付

1. 勇者之墓：克劳塞维茨流亡帝国 → 外传背景；范围在《暴风雨》至第一篇章之间。
2. 克罗：银箭特里西斯败退 → 拉希德接受训练 → 师徒分别；续集以营救妹妹为目标。最新资料尚未把本轮实际证据延伸到完整结尾。
3. 手机版第三代：三个国家并行 → 第四集兄弟对决与第一篇章收束；并非“第四集→电脑版第二篇章”已经获得移植。
4. 宇宙传奇：历史模拟中测试变量 → 海德伦试图干涉历史；第一季《方舟》把叙事带至分支自身现实 → 第二季为复活乔安继续冒险。跨章更细密顺序留给逐图核读，不用活动发行日排序。
5. 凯篇：异世界贝拉丁最终决战 → 卡尔斯幸存 → 凯与小赫尔凯特的新旅程；这一相对链由原厂应用介绍直接支持。
