# 创世纪战年表：多来源核对审计

核对日期：2026-10-18（Asia/Tokyo）。本文件区分“已读正文”“只找到目录/线索”和“直接官方叙事”，不把镜像、转载、同一 wiki 的多个域名算成多个独立证据。网页行号是本轮 web 工具读取结果的定位信息，并非网站自身稳定编号。

## 结论与数据录入规则

- 原 Naver 年表可以作为逐项整理的底本，但来源字段应诚实标注“整理年表”；它自述源于《Tempest》手册，不等于本轮直接核对了手册扫描件。
- 已查得可用的官方开发者访谈、原游戏对话转录、三线章节日期表、纪年资料、跨作品事件资料。它们各自只支持对应事件或编排原则，不能一律挂在全部事件上。
- 旧 PC 六作作为主体；《4》《灰色残影》与手游追加故事另作版本注释。2023/2024/2025 开发者访谈直接证明这些版本会修订、扩写甚至改换世界循环模型。
- 同一 Namu 内容的 namu.moe / m.namu.moe / seore / readonly 等只是可访问镜像；它们互相一致不是独立交叉确认。
- 本轮未得到可直接逐页核对的《Tempest》原版手册扫描正文，不能声称“全篇逐条官方核验”。尚只有 Naver 的极细日期应显示“底本记载/待原典核验”，不是用通用官方介绍凑第二来源。
