# 搜索、阅读与发布体验

## 找内容

全站只在顶部保留一个搜索入口，首页正文不再重复显示搜索框。电脑可按 `Ctrl+K` 或 `⌘K` 打开，输入框内的快捷键不会被抢走。手机使用全屏搜索，搜索与主题按钮在品牌右侧同行，导航链接另占一行。

搜索结果按文章、游戏档案、系列时间线分组；游戏中文名、原名和已录入别名均可检索。索引只在打开搜索时下载，失败后可重试。密码文章及未列出文章不进入索引，时间线只检索作品名称、不暴露事件和剧情。

完整搜索页支持 `/search/?q=关键词`，便于收藏和分享。原来的 `/posts/?q=关键词&tag=标签` 仍保留文章筛选功能。关闭 JavaScript 时，搜索页提供文章、游戏和时间线目录入口，不伪装成已执行全文检索。

## 读长文章

正文提供“阅读偏好”：三档字号、三档行间距，使用直接选择而不是下拉菜单。偏好只存在当前浏览器，存储不可用时仍能在本次阅读使用。已有偏好在首屏绘制前应用，避免原生返回恢复位置后因字号改变而漂移。

手机阅读正文时，左下角提供目录和字号入口。目录从底部打开，选章节后关闭并将焦点移至标题。浏览器返回键先关闭搜索、目录、偏好或图片弹层，再返回上一页；关闭后恢复原来的焦点与滚动位置。

“记住长文章阅读位置”默认关闭，可以在阅读偏好中开启。只为公开长文保存路径、章节标识、滚动位置及时间，不保存正文。30 天后的记录失效。再次访问只显示“继续上次阅读”提示，读者点击后才跳转；URL 章节锚点和浏览器原生历史恢复始终优先。

## 看懂更新与补丁说明

文章列表和正文区分首次发布时间与有效的最近更新时间；已有修订说明会在列表显示。汉化文章的“补丁与使用”入口只连接原文实际存在的下载、安装/兼容、更新章节，不猜测版本号、不生成新的下载地址，也不改写原文。

## 失败时有明确反馈

- 图片预留宽高，加载失败保留占位与重试按钮，不让后面的文字突然跳动。
- 复制失败会提示手动选择；分享不可用时尝试复制，再提供可选择的链接。
- 独立附件下载先检查同源资源；404 或网络错误明确显示并允许重试。跨站下载保留浏览器原生行为，不把“打开地址”说成“文件已下载完成”。
- 所有新增界面沿用现有动效和 reduced-motion 设置，没有增加动画依赖。

## 后台

见 [本地草稿与发布状态](publishing-experience.md)。本机备份、仓库提交、主站上线和 Pages 回退分别展示。草稿导出包含待上传文件；导入需确认且不会覆盖已有同名草稿，也不会自动发布或刷新编辑页。
