## 一、关于游戏

《真名法典：冰之魅影》（마그나카르타: 눈사태의 망령）是韩国游戏公司 SOFTMAX 开发并发行的角色扮演游戏，于 2001 年 12 月 28 日登陆 Windows 平台，也是《真名法典》系列的第一部作品。

游戏由韩国知名插画师金亨泰担任人物设计，采用 SOFTMAX 自主开发的 ASURA 引擎，以全 3D 场景结合独特的人物美术风格，在当时的韩国 PC 单机游戏中属于制作规模较大的作品。

故事围绕主人公卡林兹展开。玩家将跟随他返回故乡，加入帝国军队，在执行任务、讨伐魔物的过程中，逐渐卷入涉及帝国政局、皇室斗争与自身过去的阴谋。

战斗系统采用回合制与战场移动相结合的设计。角色可以通过调整位置、消耗行动点数发动攻击，并使用带有节奏判定的连续技。游戏还有独特的 Carta 属性系统，需要根据不同角色的特点分配属性，战斗机制相对复杂。

本作也是一部野心远超实际完成度的作品。游戏发售时便暴露出严重的程序错误，甚至出现首发实体版无法安装、频繁崩溃等问题，最终迫使 SOFTMAX 启动产品召回。其复杂晦涩的角色成长系统、冗长拖沓的战斗、频繁的读取画面、糟糕的镜头控制以及单调且缺乏变化的关卡设计，也让实际游玩体验大打折扣。这些问题并非简单的技术瑕疵，而是贯穿游戏体验的系统性缺陷。

尽管如此，金亨泰极具辨识度的人物美术、庞大的世界观设定，以及 SOFTMAX 向全 3D 角色扮演游戏转型的大胆尝试，仍然赋予了这部作品独特的历史价值。它或许称不上是一款成功的 RPG，却依然是韩国单机游戏发展历程中值得被重新认识的一部作品。

后来登陆 PS2 的[《真名法典：真红的圣痕》](https://blog.blfy.cc/posts/magna-carta-tears-of-blood-cn/)虽然沿用了系列名称和部分设定，但并不是初代的简单移植。本次汉化的是 2001 年发行的 PC 初代《真名法典》，请勿与 PS2 版本混淆。

## 二、项目背景

我最近在做《真名法典》系列的汉化，包括目前已经发布的 PS2 《真名法典：真红的圣痕》简体中文汉化版，以及正在制作的 Xbox 360 《真名法典2》。

既然都已经开始研究这个系列了，作为起点的 PC 初代自然也不能落下。

但相比后来的两部作品，初代的情况要麻烦得多。

游戏原生支持的分辨率和显示比例有限，在现代 Windows 系统上运行也会遇到兼容性问题，再加上本身 SOFTMAX 本身写的狗屎程序，制作过程中问题简直层出不穷。

我在研究过程中参考了此前国外玩家制作的英文汉化工具，解决了部分资源格式的问题。但真正开始制作简体中文版本以后，才发现需要处理的内容远远不止文本翻译。

原版使用了大量图片式界面，文字分散在不同资源中；汉字的字形、测量和排版需要单独处理；部分剧情只有语音而没有对白框；宽屏显示需要调整场景投影和界面布局；而把原来的 30 帧提升到 60 帧，也不能简单地修改帧率限制，否则容易出现人物动作和镜头异常。

于是项目逐渐从单纯的汉化，扩展成了兼容性修复、高清显示、动作插帧和游戏体验改善的综合补丁。

最终我决定将这些功能整合在一起，不再要求玩家安装多个互不关联的补丁。

## 三、简体中文汉化内容

这次汉化覆盖了游戏的剧情、界面、系统信息和相关美术资源。

文本资源经过提取、翻译、校对和重新封装，结构化文本目录共包含 4137 个字段，其中 4091 条为中文译文，另外 46 条按照既定规则保留原样。

主要汉化内容如下：

- 主线剧情、支线任务、人物对白和结局文本。
- 人物、地点、物品、装备、技能名称及相关说明。
- 游戏教程、战斗提示、系统消息和设置项目。
- 主菜单、装备界面、存取档及其他图片式界面。
- 开场和 Game Over 视频中的文字。
- 中文标题画面及重新制作的标题艺术字。
- 配套中文字库和高分辨率字形。

另外，原版存在一些只有角色语音、没有对白框的剧情演出。为了避免中文玩家在这些场景中无法理解剧情，本次为相应的语音片段补充了同步中文字幕，并制作了相应功能。

## 四、高清画面与现代化增强

本作发行于 2001 年，原版程序是为当时的 Windows 系统和图形硬件设计的。二十多年过去，游戏已经很难直接适应现代电脑的显示环境。

原版的显示比例、分辨率、窗口行为和图形接口都有明显的时代局限，而尝试直接修改这些功能，又会暴露出更多隐藏在程序内部的问题。

因此，这次并不是简单地叠加一个高清补丁，而是对游戏的图形渲染、动画系统和运行环境进行了大量研究与改造。

### 1. 高清分辨率与真宽屏

支持以下显示功能：

- 1080P、2K、4K 及自适应屏幕分辨率。
- 全屏、窗口化、无边框窗口化。
- 窗口化模式下独立设置窗口尺寸。
- 16:9 真宽屏适配，而非直接拉伸原始画面。
- 重新制作的 4K 标题背景与中文标题艺术字。
- 高清中文字形渲染，改善高分辨率下的文字颗粒感。

宽屏适配涉及的不只是场景投影，还包括菜单位置、战斗界面、鼠标坐标和部分剧情演出的布局。

原版的一些内部逻辑甚至直接依赖固定的画面宽度。修改分辨率后，可能出现菜单错位、界面异常，乃至触发程序断言而导致游戏中断。

因此，还需要进一步分析相关代码，在扩大画面显示范围的同时，保留原版系统所依赖的内部坐标和判断规则。

### 2. 60FPS 动作与镜头插值

原版游戏的逻辑更新频率约为 30Hz。如果只是强行提高帧率，不仅无法获得正常的 60FPS 体验，还可能导致人物移动加速、动作抽搐、骨骼变形和镜头抖动。

这次采用了保留原有游戏逻辑速度、提高画面呈现频率的方案，加入人物与怪物模型插帧、镜头插值及帧时间控制。

实际开发过程远比预想复杂。

最初的人物插帧存在大量问题：待机时看起来正常，一旦开始移动，模型便可能出现伸缩、抽搐；解决人物动作后，又出现了镜头抖动、移动与停步过渡不连续等现象。

为此，针对原版动画和绘制流程进行了多轮修正，包括：

- 骨骼矩阵、旋转、缩放及特殊变换的插值处理。
- 人物移动、待机与不同动作之间的过渡。
- 模型世界坐标与原生绘制队列的同步。
- 场景镜头采样与人物动作的协调。
- 60FPS 呈现节奏及帧时间漂移修正。

经过反复调整，测试场景中的人物动作和镜头平滑度已经得到实际验证。

不过，考虑到原版动画系统的复杂性，部分特殊动作、战斗镜头和剧情演出仍可能出现异常，因此保留了 30FPS / 60FPS 切换功能，方便玩家根据实际情况进行选择。

### 3. 旧图形接口与现代 Windows 兼容

原版使用早期 Direct3D 等图形技术，与现代显卡驱动和 Windows 桌面管理机制之间存在兼容性问题。

在研究过程中，遇到过启动初始化失败、窗口切换异常、鼠标输入丢失、显示恢复失败等情况。

比如，游戏原本就有的经典问题就是使用 Alt+Tab 切换到桌面以后 100% 无法重新回到游戏。

经过调查发现，这类问题不只是显卡驱动的问题，还涉及原版窗口最小化逻辑与 DirectDraw 图形激活流程。

为了解决这类问题，对窗口焦点、图形设备激活、鼠标坐标和显示模式切换等部分进行了针对性处理。

部分问题已经通过实际测试获得改善，但不同显卡、驱动和显示环境仍可能存在兼容性差异。

### 4. 免光盘与运行环境整合

整合了针对匹配游戏版本的免光盘启动修正，以及现代 Windows 所需的兼容组件。

安装完成后，不再需要为了启动游戏挂载原版光盘镜像，也无需自行寻找和组合多个兼容补丁。

同时，将原先分散的启动与配置功能整合为独立的桌面程序，玩家可以直接通过图形界面设置显示模式、分辨率和帧率。

## 五、原版程序缺陷与修复工程

如果说汉化是为了让玩家读懂游戏，那么另一项重要工作，就是尽可能让这款二十多年前的游戏能够正常运行和游玩。

本作在程序稳定性方面一直存在不少问题，从场景切换、角色移动，到剧情对白、战斗菜单和声音播放，许多问题并不是简单修改配置就能够解决的。

项目开发期间，为了排查这些故障，需要分析原版执行文件、追踪汇编指令、研究游戏资源格式，结合运行日志、异常转储和实际游戏反馈，不断缩小问题范围。

一些看似简单的显示异常，实际可能涉及多个底层模块。修正其中一处，又可能引出新的兼容性问题，因此整个过程也经历了大量测试、失败和返工。

### 1. 剧情对白与语音播放异常

原版部分长对白存在显示与语音时序不一致的问题。

有时角色还没有说完台词，语音就已经被提前截断；有时对白文字还没有完整显示，游戏便开始执行下一步剧情。

这些问题不仅影响阅读，也可能导致玩家漏掉重要剧情。

为此，对原版对白揭示、翻页、语音播放状态、剧情等待及转场流程进行了分析，并针对部分提前结束和显示不完整的情况加入运行时修正。

另外，原版还存在部分只有角色语音、没有对白框的剧情演出。

本次针对这些独立语音片段补充了同步中文字幕，并加入与原版对白框之间的优先级判断。正常对白框出现时优先保留原版显示，避免两套字幕同时出现。

### 2. 场景切换、资源载入与程序崩溃

原版的场景切换和资源管理也是比较棘手的部分。

在一些情况下，玩家快速往返不同区域时可能出现崩溃；场景载入过程中，还可能会黑屏或 Loading 显示异常。

为了排查这些问题，对原版的场景状态、资源加载与释放、GUI 对象访问以及图形资源生命周期进行了研究。

最终发现部分 GUI 对象的内部结构被错误解释，导致程序读取了不属于该对象的字段，并针对这一问题制作了修正。

不过目前特定场景切换崩溃仍未完全定位和解决。

### 3. 人物卡墙与场景碰撞缺陷

原版部分地图存在相当令人头疼的碰撞问题。

角色在贴墙移动、穿过狭窄通道或者接触某些场景物体时，可能被挤入墙体内部，随后无法正常移动，也无法从障碍物中脱离。这种问题一旦发生，往往只能重新读取存档，损失之前的游戏进度。

其中，一些迷宫区域和建筑物周围的问题尤其明显。

为此，分析了原版人物位置更新、碰撞检测、场景高度以及移动状态处理，并针对特定楼梯事件的高度异常制作了修正方案。对于更普遍的卡墙问题，还研究了通用的位置检查与局部脱离机制，希望在不改变原版移动手感的情况下，降低角色陷入场景物体后无法恢复的概率。

但通用碰撞问题牵涉原版的地图结构和物理处理，目前还不能宣布彻底修复。部分候选方案仍处于独立测试阶段，不作为已验证功能对外承诺。

### 5. 战斗菜单与伤害数字异常

原版战斗界面也存在不少需要深入程序内部才能解决的问题。

其中一个问题与宽屏适配直接相关。

部分战斗菜单的内部判断依赖原版画布尺寸。当游戏改用宽屏以后，某些判断会错误地读取扩展后的显示宽度，进而触发断言，严重时直接导致游戏中断。

经过分析后，对相关判断进行了修正，使游戏能够在保持宽屏显示的同时，继续使用正确的原生逻辑尺寸。

另一个问题是伤害数字的位置异常。

在部分角色、技能和特殊镜头中，原版伤害数字可能出现在错误的位置，甚至偏移到画面边缘。

为此，对角色模型的空间变换、伤害投影、模型可见性及原生数字绘制流程进行了分析，并修正了部分错误读取位置和投影状态的问题。

### 6. 连招声音与音频通道问题

开发中还发现，战斗连续技进入后半段时，角色语音和打击音效可能突然消失。

进一步分析原版声音后端后，发现其可用的 3D 声音通道数量有限，在多个音效集中播放时，可能出现声音分配失败。

因此，针对音频分配、播放顺序和声道资源进行了研究，并制作了相应的改进方案。

### 7. 图片资源、字体与界面结构修复

本作的许多界面文字直接保存在图片资源中，这种设计让汉化工作变得十分繁琐。

为此，除了重新绘制中文资源，还针对原版图片的分块方式、透明区域、界面布局和字形渲染进行了检查与修正。

另外，还对中文字形的尺寸、描边、测量和高分辨率渲染进行了调整，尽可能保持原版美术风格与中文显示效果之间的一致性。

### 8. 修复工作的测试与取舍

这次最花时间的部分，其实不完全是实现新功能，而是不断验证这些修改有没有破坏原版程序。

尤其是这样一款年代久远、缺少完整技术资料的游戏，很多问题只能通过分析原始指令、检查资源结构和反复测试来定位。

开发过程中也遇到过不少情况：一个补丁修好了窗口，却影响了鼠标输入；修好了人物插帧，又出现镜头抖动；改善了场景载入，却在某些条件下引入新的异常。

因此，项目保留了大量测试记录、资源校验工具和可撤回的修正方案，并尽可能区分已经验证的功能与仍处于调查阶段的改动。

这次的目标不是宣称修复了原版所有 Bug，而是尽可能解决已经明确定位的问题，同时避免为了加入新功能而破坏游戏原有的正常流程。

## 六、地图、战斗辅助与游戏体验改进

除了底层程序修复，本次还加入了几项原版没有的辅助功能。

这些功能主要针对游戏原有的一些不便之处，例如复杂的迷宫、频繁的随机战斗，以及需要反复进行节奏判定的连续技。

它们不会改变游戏的主线剧情和基本玩法，而是希望让今天的玩家在体验这部老游戏时，能够少受一些折磨。

### 1. 全新区域地图

本作的场景和迷宫结构比较复杂，部分区域的道路十分相似，再加上固定镜头和早期 3D 场景的表现方式，很容易让玩家失去方向感。

因此，本次补丁加入了区域地图系统。

按 F9 可以依次切换：

- 小地图。
- 全屏半透明地图。
- 关闭地图。

目前地图数据覆盖 174 个区域，可以辅助玩家了解当前区域的道路和大致结构。

地图采用区域线稿方式呈现，并非完整的自动寻路系统。部分多层结构可能叠合显示，另外两个特殊区域暂时没有地图。

### 2. 随机遇敌开关

原版某些迷宫的随机遇敌相当频繁，尤其是找不到路线、需要反复往返时，不断进入战斗会明显拖慢探索节奏。

因此，加入了 F5 随机遇敌开关。

关闭后可以避免普通随机战斗，但不会影响剧情强制战斗，也不会中断已经开始的战斗。

每次重新启动游戏时，随机遇敌默认恢复开启。

玩家可以根据自己的游玩习惯决定是否使用。

### 3. 普通连招与暴走连招辅助

本作的战斗系统要求玩家按照指定节奏完成连续技判定。

虽然这种设计有一定特色，但大量重复操作也容易让战斗变得繁琐，尤其是后期技能和暴走模式的连续判定。

因此，本次加入：

- F10：普通连招辅助。
- F11：暴走连招辅助。

这两项功能针对原版连招判定机制进行处理，尽量保留正常的动作选择和战斗流程，减少玩家反复进行节奏输入的负担。

不需要辅助的玩家可以继续按照原版方式操作。

### 4. 图形化配置与文件校验

考虑到这次补丁涉及大量资源文件、原生模块和运行组件，安装不完整、版本不匹配或者混用旧补丁，都可能造成游戏异常。

因此制作了独立的桌面配置与启动程序：

- Configure.exe：图形化设置、恢复默认、检查入口和启动游戏。
- Game.exe：直接启动游戏，并提供安装校验及原版资源恢复等功能。

## 八、安装与使用方法

本次发布的是 v1.0 完整补丁，已经整合了汉化和增强功能。

### 安装步骤

1. 准备与补丁匹配的 PC 原版《真名法典：冰之魅影》。
2. 退出游戏，建议先备份游戏目录和个人存档。
3. 下载 `MagnaCarta-zh-CN-v1.0-release.zip`。
4. 将压缩包内的全部文件解压到 `MagnaCarta.exe` 所在目录，覆盖同名文件，保留原有目录结构。
5. 运行 `Configure.exe`，点击「检查入口」，通过后设置分辨率、显示模式与帧率。
6. 保存设置并启动游戏，也可以直接运行 `Game.exe`。

补丁提供图形化配置工具，默认配置为 1080P、无边框窗口化、60FPS。

设置保存在游戏目录的 enhancements.json 中，后续覆盖更新不会主动清除玩家设置或移动存档。

### 快捷键一览

| 按键 | 功能 |
| --- | --- |
| F5 | 开启／关闭随机遇敌 |
| F9 | 切换小地图、全屏地图或关闭地图 |
| F10 | 普通连招辅助 |
| F11 | 暴走模式连招辅助 |

### 注意：

- 本补丁不包含完整游戏，必须自行准备匹配版本的原版文件。
- 当前 v1.0 以键盘和鼠标操作为主，不包含正式的手柄支持。
- GitHub 自动生成的 Source code 压缩包只是工程源码，不是可直接安装的汉化补丁。
- 以前安装过测试版的玩家也可以直接使用完整补丁覆盖，不需要依次安装旧版更新。

### 管理员权限与 UAC 说明

本补丁采用按需申请管理员权限的方式，正常情况下无需管理员身份运行游戏。

如果游戏安装在 `C:\Program Files`、`C:\Program Files (x86)` 等受 Windows 保护的目录中，配置工具在保存设置或修改相关文件时，可能会触发 Windows 用户账户控制（UAC）提示。

这是因为部分操作需要向游戏安装目录写入文件，如果对此有疑虑，建议将游戏安装在 `D:\Games\MagnaCarta` 等具有正常读写权限的独立目录，通常可以避免不必要的权限提示。

## 九、测试情况与已知问题

目前主要需要注意以下问题：

- 区域地图：部分多层区域的线稿会叠合显示，个别特殊区域没有地图。
- 60 帧模式：特殊人物动作、战斗镜头及个别过场仍可能出现显示异常，可以切换 30 帧对照。
- 场景碰撞：部分狭窄区域可能发生角色卡墙问题，相关修正仍有待进一步验证。
- 战斗声音：部分连续技后段存在角色语音或打击音效缺失的反馈，尚不能保证完全解决。
- 运行兼容性：不同硬件、显卡驱动、分辨率以及 Windows 环境可能出现不同结果。

如果遇到问题，欢迎在 [GitHub Issues](https://github.com/jyh9521/Magna-Carta-The-Phantom-of-Avalanche-CN/issues) 中提交反馈，最好附上游戏版本、出问题的场景、具体复现步骤、截图以及运行日志。

## 十一、最后

作为《真名法典》系列的起点，也是 SOFTMAX 当年投入大量资源开发的 3D 角色扮演游戏，我觉得本作还是值得被重新整理和体验的。

最初只是想给这款游戏做一个完整的简体中文汉化，后来逐渐加入宽屏、高清分辨率、60 帧、地图、战斗辅助和兼容性修正，最后的工作量已经远远超过最开始的计划。

这些改动当然不能从根本上改变原版的游戏设计，但至少可以减少语言障碍、运行问题以及一些不必要的重复操作，让今天的玩家能够更方便地接触这部作品。
