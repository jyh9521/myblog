# 多行代码块

文章正文与时间线说明共用「插入代码块」按钮。点击后，将整段代码一次粘贴到「整段代码」字段；语言可选填 `toml`、`json`、`bash` 等，留空为纯文本。

工具栏的「代码」是行内格式，用于文件名或短命令，不用于包住多段配置。Sveltia CMS 0.256.1 的「文本样式 → 代码块」会按选区内的段落转换；跨段落选择可能得到多个独立代码块。新的按钮使用单个多行文本字段，避免这条转换路径。

## 已经逐行设置的代码

复制原始完整代码，删除文章里错误的逐行片段，在原位置点击「插入代码块」，再一次粘贴。不要把正文中其他正常的行内代码全部替换。保存前可在右侧预览检查只有一个框。

当前编辑器中的未保存内容应先保留，再刷新以载入新工具栏。

## 数据与兼容

- 使用 CMS 公开的 `registerEditorComponent` 块组件 API，不访问私有 Lexical 对象，也不修改粘贴事件。
- 保存为标准 Markdown 围栏代码块，无新增前台语法。既有代码块、行内代码及前台「复制代码」按钮继续使用原实现。
- 换行统一为 LF，其余文字、空行、缩进、半角引号与末尾换行保留；代码里的 HTML/Markdown 作为原文显示。
- 自动选择比内容中连续反引号更长的围栏，避免嵌套代码提前截断。
- 同时将《真名法典2》文章中已保存的 39 个逐行代码片段合为一个 TOML 代码块，仅去除行内反引号并添加围栏；代码数值、空行及其他正文保持原样，不批量改写其他文章。

参考：[Sveltia 编辑器组件公开 API](https://sveltiacms.app/en/docs/api/editor-components)。
