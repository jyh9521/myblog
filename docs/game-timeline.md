# 时间线编辑

游戏档案的「时间线事件 → 事件」为单选下拉框，固定为：开始游戏、通关游戏、开始汉化工作、开始测试汉化、已发布汉化补丁、AFK。日期、顺序和说明独立保留；当前状态的多选字段不变。

「说明」复用文章正文的 `richtext` 编辑器与相同的编辑器组件：标题、粗体、斜体、列表、引用、链接、表格、代码块、图片、游戏卡片、截图对比、分隔线和 PDF。插图使用共用 R2 资源库；现有纯文本无需重新输入，单换行继续显示为换行。

前台复用 `PostContent` 的 compact 模式，只去除文章专用的阅读进度、分享栏和目录，保留 Markdown 渲染、图片说明、放大浏览及其他正文组件。时间线节点样式限定到外层列表，不影响说明里的列表和粗体。

旧事件已迁移到固定选项，霍格沃茨的 Xbox / Switch 2 版本信息保留在说明中。「已通关」作为当前状态的名称保持不变。

新增说明里的资源引用纳入构建资源索引和内容校验，避免已使用的插图被当成未引用资源。修改文章编辑器组件列表时，同步更新时间线说明；回归测试检查二者一致。

验证：`node --test scripts/game-timeline.test.cjs`，以及 `npm test`、`npm run check`、`npm run validate`、`npm run build`。
