## 差异、错误与处理

1. **米歇尔身份矛盾**：攻略(8)同页先称阿修雷的恋人，后又写作妹妹；阿修雷长条目叙述恋人关系。本数据不写这层关系，避免把攻略笔误带进年表。
2. **海德伦不是永久同一姓名**：第4章群的职衔与第5章群的克里斯蒂安需分清；不能把前期一切该职衔的行动归于克里斯蒂安。
3. **贝拉莫德不是“萨拉丁单独转世”**：第5章群终章将青年诞生与雪拉扎德灵子、萨拉丁Doll、阿修罗保存的灵魂并列说明。条目1902/1982保留组合关系。
4. **红发死亡的证据强度**：Naver1970行明确写红发与露西恩均遭杀害；攻略(13)明确露西恩死亡，红发则留后掩护。1970条目保留“红发殿后”，注释交代原年表更强的断言。
5. **谁首先命名安塔利亚**：攻略(13)写启航时约定目的地名称，Naver2008行写抵达后命名。两者不必然冲突，但只能写各自支持的阶段，不应声称已锁定命名的唯一天时。
6. **循环重演的身份不是全无争议**：旧百科明确把青年以后再扮演贝拉丁等角色列作通常解读，并承认细节不确定。未公开录音亦不可自动算正式游戏画面。年表可展示首尾相连的宇宙结构，勿写“已证实每轮每人完全重复”。
7. **结局不应被压成一次发射**：奥德赛起飞、转向、潜入、阿修雷死亡、贝拉莫德与海德伦交战、暗黑血、兄弟诀别、电脑真相、宇宙再生、抵达命名，已分别保留，便于逐项查阅。
8. **露西恩如何离开拘禁**：原年表1932行写获释；攻略(11)的“폐기장 3 / 붙잡힌 루시엔 / 무사히 돌아온 루시엔”写被捕后脱逃，再由阿塞拉斯带回。因此正文使用“后来脱离拘禁”，不指定是军方主动释放。
9. **单来源项目明确标记**：1908行露西恩开始记者工作、1936行四人毕业、1962行兰离院去梅特罗斯的具体说法，本轮没有取得独立的逐项支持。三条保留原年表覆盖，但 `evidenceStatus=source-only`、`extraSources=[]`，不挂泛泛的攻略链接冒充核对。

## 字段和集成建议

每个JSON对象包括请求的 `title / summary / year / sourceUrl / sourceTitle / notes / keywords`，并增加 `sourceLineStart / sourceLineEnd / corroboratingSourceUrl / corroborationScope / works / spoilerWorks`。作品ID采用正式 `genesis-3-p2`，主任务按正式模式映射；本文件不自行修改公开内容或前端。

追加字段 `dateStatus` 逐项标明纪年尚未独立确认；`evidenceStatus` 区分剧情交叉核对与仅原年表；`corroboratingLocator` 与 `extraSources[].locator` 给出实际阅读的章节或角色条目小节。关联来源只支持该条剧情，不自动验证原作者年号或全部附带数字。

默认全部事件都应按《创世纪战3 Part II》剧透控制；青年身份、灰色幻影身份、海德伦身份、宇宙结构尤其不能在未开放作品时泄漏标题。
