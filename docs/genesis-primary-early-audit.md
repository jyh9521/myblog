# 早期年表原典复核与误挂清理

核验日期：2026-10-18（日本时间）。范围：神话、纪年前史、Ⅰ／Ⅱ战争及1262年前战后，共99条。此报告逐项说明实际检查范围，不把未取得的原典写成已经读过。

## 本轮直接得到的纠正与边界

1. **75人不是已死而复活。**《Ⅱ》石板对白1023说75人陷入假死，1033说旧同伴苏醒；改正事件47、65。对白由第三方从原版文本转录，本轮逐段核读，没有声称本机抽取。
2. **埃里希不是直接被确认为暗黑神。**第22章第33—37张原画面显示加里乌斯拒绝操纵、格里玛单位、拉希德认出格里玛、兰达姆发问是否德布尔族。原表把变身写成暗黑神身份，现按原画面修正，不把后出血统设定当旧版台词。
3. **三反对神的原表名单反而正确。**第30章第77张原画面中弗莱奥斯明确点名维斯巴登、奥布斯库拉、阿比多斯；攻略作者正文误列拉埃维乌斯。其第73张原画面恰显示拉埃维乌斯赞成归乡。本次保留底本正确名单、记录攻略正文错误。
4. **圣王大会是黑太子死后次年。**原版结局滚动字幕显示1213去世，随后“次年”九国缔约、拉希德成为盟主与圣王，推得大会在1214。此为有明确前提的算术推导；字幕没有直接定义“圣王纪年元年”的文字规则。底本标题1213元年、后表1217=4年仍有内在冲突。可将和平大会拆入1214；杜兰追谥和白金汉授爵还缺手册页，不能整组强行定年。
5. **罗宾1226是另一作品索引。**现有二手条目脚注A将1228归于《暴风雨》手册，脚注B将1226归于《创世纪战4》百科。没有取得两份原典；建议旧PC1228保留单源，后出异说单列，不继续称为旧PC同一版本内已证实冲突。
6. **撤掉不对应场景的第8篇泛引。**原第8篇只到对白1415。其含柯蒂斯共和国讨论、阿斯塔尼亚求援、诸神不干预、武斗及灰色骑士团构想，但没有诸神归乡商议、人类结盟、卡琳海盗及卡嘉护航组。按实际章节替换，商路两条未得到完整原典的保守退回单源。
7. **精细日数没有借攻略正文自动升格。**第26章作者正文写1212第10日，逐图所见却不带日期。对白转录出现“限制时段”制作资料；其包含未用文本，不能不经实机对应就当正式发生日。魔塔对白970说每年第1—20日冰封窗口，和底本1208年末编排的具体关系仍待核，不隐式改日。

## 包装手册追查：找到什么、没找到什么

- [《暴风雨》附件页](https://doogie838.tistory.com/121)确有单独的手册附件；只读取了350,289字节的附件，没有下载或运行完整游戏。附件SHA-256见私有证据目录的哈希清单。
- 解包后是6份HWP攻略／卡片／提示文档与1张人物关系图，文件时间约2004年；其中“总整理”预览以塔罗卡获得方式开头。**它不是原包装说明书扫描**，目录名“Manual”不能作为官方原典身份凭据。关系图也不含出生／死亡年份。本轮不把这批文件加入公共年表引证。
- 另查了“说明书／手册／扫描／初版”与书目、收藏展示线索，搜索命中多为商品封面、收藏照片或攻略，没有取得能直接阅读1228、1250、1251、海伦身份等行的原包装页。商品与封面不能证实内容，故不作为年表佐证。
- 当前本机既有《西风狂诗曲 复刻版》Steam目录存在但为空。没有读取到原PC或重制版剧情文件，更没有修改其他项目。旧工作记忆不能充当当前游戏资料证据。
- 希拉诺／希罗尼等历史中文名称本轮没有新增原版中文画面依据；采用主任务统一名，不借旧攻略转载冒称官方译名。
