## 一、项目背景

《时光之轮》（The Wheel of Time）是由 Legend Entertainment 开发、GT Interactive 于 1999 年发行的第一人称奇幻动作游戏，改编自罗伯特·乔丹（Robert Jordan）的同名奇幻小说系列。

与传统的第一人称射击游戏不同，本作以特法器代替常规枪械，玩家需要利用不同法器的攻击、防御与特殊能力应对敌人、解开机关并探索场景。

游戏使用初代虚幻引擎，融合了动作战斗、环境探索、机关解谜与剧情叙事。以今天的标准来看，其关卡设计、美术氛围和魔法系统仍有值得体验的独特之处。

由于年代久远，加之游戏本身从未提供官方简体中文支持，语言一直是中文玩家深入体验本作的一大障碍。本项目希望在尽可能保留原作表现与玩法的前提下，为这部经典游戏提供完整、自然且符合原著世界观的中文体验。

### 关于译名

《时光之轮》拥有庞大的世界观，其中包含大量人物、地点、组织、魔法及专有概念。

为避免出现同一名词在不同场景下译法不一致的问题，本项目建立了统一术语表。

汉化时优先参考：

- 《时光之轮》系列小说的中文出版译本。
- [时光之轮中文 Wiki](https://twot.huijiwiki.com/wiki/%E9%A6%96%E9%A1%B5)所整理的世界观资料。
- 游戏自身的英文文本、剧情语境与原创设定。

对于小说中已有成熟译名的人名、地名和专有名词，原则上沿用既有中文译法；游戏原创内容则根据上下文重新翻译。

希望这套汉化不仅能够让玩家读懂游戏，也能尽可能保留《时光之轮》原有的奇幻文学气质。

## 二、汉化内容

本次汉化不局限于菜单和剧情对白，而是针对游戏内的各类可见文本进行系统性整理。

主要包括以下内容：

### 1. 游戏界面

- 主菜单、设置菜单及各级子菜单。
- 操作设置、画面设置与高级选项。
- 物品栏、法器名称及说明。
- 游戏提示、状态信息及系统消息。
- 首次运行配置向导及部分图片按钮。

### 2. 剧情与游戏文本

- 主线剧情及任务目标。
- 游戏内人物对白与旁白字幕。
- 教程文字、机关提示与交互信息。
- 地图名称、场景说明及相关文本。

### 3. 过场动画中文字幕

为 14 段带文本轨的剧情影片制作 628 条中文字幕，并保留原有配音与视频内容。

### 4. 中文字体与显示适配

游戏菜单与物品说明基本保留原始字号，游戏内对白则使用独立的 18px 字幕字体，以改善阅读体验。

## 三、技术说明

《时光之轮》基于初代虚幻引擎开发，其文本资源、字体渲染、UnrealScript 运行时与 QuickTime 过场动画系统均具有明显的时代特征。

本项目并非传统的文本替换式汉化，而是围绕游戏内部资源结构建立了一套涵盖资源逆向、Unicode 本地化、字库生成、脚本重构、原生字幕适配、二进制差分构建及完整性校验的本地化工具链。

### 1. 虚幻引擎资源逆向与重建

对游戏原始 `.u`、`.utx` 等 Unreal Package 资源进行结构分析，研究包内名称表、导入表、导出表、对象引用及序列化数据之间的关联。

针对本地化资源，构建可重复执行的提取、转换、校验与重建流程，在保持原始对象依赖和资源结构有效性的前提下，将中文内容重新整合至游戏资源中。

- Unreal Package 二进制结构解析与资源重建。
- 对象引用、名称索引及导出数据一致性维护。
- 基于 SHA-256 的原始资源指纹识别。
- 差分构建、目标资源验证与可逆性校验。

### 2. Unicode 本地化与中文位图字体重构

原版游戏采用面向西文字符集设计的字体资源及固定尺寸 Canvas 绘制机制，无法直接满足大规模中文字符的显示需求。

项目针对虚幻引擎的原生字体资源进行重新构建，实现中文字形与游戏内部字符索引的映射。

- 支持 UTF-16 LE BOM 格式的本地化文本。
- 基于实际译文动态收集所需中文字形。
- 自动生成符合原版引擎约束的 P8 调色板字体图集。
- 重建字符映射、字形度量及相关字体资源。
- 保留原有西文字符映射及引擎资源兼容性。

通过对字体分页、图集尺寸和序列化结构的适配，使中文直接参与游戏原生 UI 渲染，而非依赖外部文字覆盖层。

### 3. UnrealScript 字幕系统重构

针对原版字幕系统在中文排版、多事件触发及显示时序上的限制，基于 UnrealScript 实现独立的字幕运行时与显示层。

该系统通过专用 `SubtitleFont` 和 `SubtitleHUD` 接入游戏原生 HUD 绘制流程，同时保留菜单、物品栏等其他界面的原始字体规格。

主要实现包括：

- 独立的 18px 中文游戏字幕渲染层。
- 基于事件触发与时间控制的字幕生命周期管理。
- 多字幕队列管理及并发显示处理。
- 重复字幕事件合并与旧状态过滤。
- 原生 UCC 编译、资源加载及运行时验证。

字幕处理直接集成至引擎运行时，无需第三方字幕挂载程序。

### 4. QuickTime MOV 原生字幕轨重建

游戏 FMV 采用 QuickTime MOV 容器，并通过原生文字轨及播放器接口处理字幕显示。

本项目针对 MOV 内部文字样本、时间表及字幕轨选择机制进行分析，实现中文字幕的原生替换与重建。

- 解析 QuickTime 文本轨及字幕样本结构。
- 重建 14 段剧情影片、共 628 条中文字幕。
- 保留原始字幕时间轴、样本间隔及空白区间。
- 对播放器的字幕轨选择逻辑进行二进制级适配。
- 通过进程私有字体加载机制提供配套的思源黑体子集。
- 保持原始视频和音频数据不重新编码。

整个流程不依赖视频硬字幕压制，而是保留 QuickTime 原生字幕渲染路径，实现中文文字轨与原版影音资源的整合。

### 5. 原生界面与硬编码文本适配

部分界面文本并非来自常规本地化文件，而是存在于 UnrealScript 类默认属性、菜单逻辑及原生 Windows 控件中。

针对这些内容，项目进行了专项逆向与适配：

- UnrealScript 类默认属性及动态显示值本地化。
- 原生 `Window.dll` 界面绘制参数适配。
- 设置菜单反射属性、分类名称及动态选项汉化。
- 地图内嵌提示、任务目标及交互文本提取。
- 游戏图片按钮纹理替换与资源重建。
- 配置值与显示文本分离，保持原有逻辑行为。

### 6. 自动化构建与完整性验证

项目使用 Python 构建模块化本地化工具链，将译文数据、术语管理、字体生成、资源封包与补丁构建相互分离。

- 基于结构化语言数据的文本管理。
- 翻译控制符、资源键及术语一致性校验。
- 自动化字体子集生成与缺字检测。
- Unreal Package 资源重建与二进制差分生成。
- 原版 SHA-256 指纹校验及修改范围约束。
- 独立测试副本的资源验证与精确回滚测试。
- 自动化回归测试与构建结果一致性检查。

本地化构建流程采用语言无关的工具设计，中文译文与底层资源处理逻辑相互独立，如果后续有人想为《时光之轮》扩展其他语言，本项目可以提供坚实的基础。

完整技术实现与开发资料可参阅 [GitHub](https://github.com/jyh9521/The-Wheel-of-Time-CN)。

## 四、安装方法

![《时光之轮》简体中文汉化补丁安装器](/uploads/chinesetranslationpatch/thewheeloftime/%E5%AE%89%E8%A3%85%E5%99%A8.png "《时光之轮》简体中文汉化补丁安装器")

本汉化补丁适配 《时光之轮》GOG 版（Build 333b），请先确认游戏版本符合要求。

1. 从下载最新版简体中文汉化补丁。
2. 双击运行汉化补丁安装程序，无需额外安装其他软件。
3. 点击「浏览…」，选择《时光之轮》的游戏根目录，即包含 `System`、`Maps` 和 `Movies` 文件夹的目录。
4. 点击「验证文件」，等待程序检查游戏版本及文件完整性。
5. 验证通过后，点击「安装补丁」，等待安装完成。
6. 安装成功后，使用原有的 GOG 游戏快捷方式启动游戏即可，无需通过安装器启动。

注意事项：

- 建议使用未经修改的 GOG 原版游戏。 如果安装过其他 MOD，文件校验可能无法通过。
- 推荐使用 1024×768 分辨率，以获得更清晰易读的界面文字；最高不建议超过 1920×1080。
- 安装器会自动备份需要修改的原始文件，请勿删除游戏目录中的 `backup` 文件夹。
- 汉化补丁不会修改系统注册表或创建系统卸载项，并会保留现有游戏设置与存档。

### 卸载汉化：

重新运行汉化补丁安装程序，选择已经安装汉化的游戏目录，点击「恢复原版」，即可通过备份恢复原版游戏资源，无需重新下载或安装游戏。

## 七、问题反馈

由于原版游戏年代久远，加之其引擎、文字系统和视频播放技术均存在一定限制，汉化过程中难免会有遗漏和问题。

如果在游玩过程中遇到以下情况，欢迎反馈：

- 文本漏译、错译或专有名词不统一。
- 中文字体缺字、乱码、截断或重叠。
- 游戏内字幕显示异常或与配音不同步。
- 过场动画字幕缺失、播放异常。
- 安装、恢复及其他兼容性问题。

问题反馈地址：

[https://github.com/jyh9521/The-Wheel-of-Time-CN/issues](https://github.com/jyh9521/The-Wheel-of-Time-CN/issues)

提交反馈时，最好附上游戏版本、问题出现的关卡或场景、详细复现步骤及截图。

如果涉及崩溃，也欢迎附上相关日志，以便定位问题。

需要注意，本项目为非官方汉化补丁，无法保证兼容所有非官方游戏版本及第三方 MOD。

## 八、最后

《时光之轮》即使在它发售的年代，其战斗节奏、难度设计以及部分操作体验也颇具争议。放到今天，这些旧时代游戏设计所带来的不便或许会更加明显。

但它同样拥有自己的独到之处，比如令人印象深刻的奇幻氛围、独特的魔法战斗系统等。

对我来说，为老游戏制作汉化，并不是为了把它们包装成毫无缺点的经典，而是希望消除语言障碍，让今天的玩家仍然有机会亲自体验、理解并评价这些作品。

或许它们早已离开主流视野，但只要还有人愿意重新打开这些游戏，它们就不应该仅仅成为游戏史上的一个名字。

希望这份汉化能够让更多中文玩家走进《时光之轮》的世界。

时光流转，轮回不息。
