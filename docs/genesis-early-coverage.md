# 创世纪战早期年表：覆盖与证据

- 核验日期：2026-10-18（Asia/Tokyo）。
- 输入：`genesis-page-evidence-20261018/naver-source.txt` 第47—826行。
- 输出：99条独立中文事实记录，覆盖341条原始破折号事件；遗漏0、重复覆盖0。
- 范围：神话时代—1262年；1263年开始的西风可玩剧情由后续部分整理。
- 原文为基于《暴风雨》手册的个人编纂，不是统一的官方终稿。神话、删节剧情、未定身份、版本分歧在条目note中单独保存。

- 日序多数只有Naver原编者支持；实机流程能印证事件，不自动印证某年第几日。
- Namu各域名与seore镜像按一个社区资料家族计算，不虚增独立来源数。

## 显式保留的分歧

- 圣王元年：Naver标题写1213，后面的1217=圣王4年又对应1214；Ⅱ代结局所说“次年”与后者接近。保留而非隐式修正。
- 罗宾死亡：旧年表1228；其他版本存在1226。
- 禁书事件：Naver1250约第50日；人物资料有1249年末订婚日。
- 伯恩斯坦灭门：Naver1251；罗温条目记1250。
- 海伦·潘德莱肯：原编者无法确定身份；只以待考条目保留。
- 水下都市的阿巴雷斯特、卡琳、阿泽罗斯与艾琳等：原表明确标注游戏删节/手册独有，不改写成游戏必经事件。
