# 文章访问方式

文章编辑页的「文章访问设置」提供公开、密码访问、仅链接可见。
旧文章默认为公开，不需要修改。

## 编辑和发布

- 公开：继续使用原富文本 / Markdown 编辑器与公共资源库。
- 仅链接可见：不在列表、搜索、RSS、推荐、游戏关联文章列表展示；独立页面仍能直接阅读，设置 noindex。保存后复制分享链接或预览网址。
- 密码访问：第一次转换时设置至少 6 个字符的密码，再保存文章。保存钩子将原正文上传到私密存储，Git 中的正文仅保留引用。
- 再次编辑密码文章：先「载入私密正文」，在私密 Markdown 编辑器修改；可以先保存私密正文，再保存文章。修改标题、摘要、封面仍需发布 GitHub Pages。已有密码留空保留；修改正文或密码会撤销先前的阅读授权。
- 如果提示未登录，在访问设置内连接后台；使用与游戏平台管理相同的管理员身份验证和 HttpOnly 会话，GitHub token 不写入文章也不保存在浏览器。
- 密码文章的图片 / PDF 使用私密资源上传，最大 5 MB，支持插入、删除及 PDF 内嵌。原公共资源库和封面、摘要仍公开。音频、视频、附件字段需要清空；可在正文中用私密 PDF 链接。
- 返回公开或仅链接可见时，先载入并复制私密正文到原编辑器，再选择访问方式并保存。公开发布会将正文写入 Git；原 Git 历史和已发布的公共附件不因加密码而自动消失。

## 存储和访问

GitHub 保存公开元数据与 `access.mode`、`access.privateId`。密码正文通过 AES-GCM 加密保存在现有 D1 中，密码使用随机盐及 PBKDF2-SHA256（100000 次）派生，不保存明文密码。
私密文件存入 D1 分块 BLOB；不依赖尚未启用的 R2，也不产生公共下载链接。

Worker `/ns/api/posts/*` 提供管理员编辑、私密资源和访客解锁接口；只允许站点同源修改。
访客输入正确密码后取得文章专属 HttpOnly/Secure/SameSite=Strict cookie，12 小时有效。
每个 IP / 文章每 10 分钟最多尝试 5 次；所有正文和私密文件响应为 no-store，PDF 支持 Range 请求。
私密内容不会注入静态 HTML、RSC、JS、RSS 或搜索数据；构建和内容校验拒绝密码正文混入静态源文件。
仅链接可见不是鉴权：链接可转发，公开仓库中的源码也可被发现。

## 部署和维护

应用 `workers/gaming-accounts/migrations/0004_private_posts.sql`，部署同一 Worker 的新增路由，沿用已有管理员配置和加密密钥；无需新增秘密或第三方认证。
加密密钥必须保留备份，密钥丢失意味着私密正文无法解密。
管理员 `DELETE /ns/api/posts/admin/{privateId}` 可删除该私密正文和全部资源，立即撤销阅读访问；删除 CMS 文章不会自动执行该操作，以免误删或 Git 回滚丢失正文。
源码回滚不会删除 D1 数据。仅恢复原公开文章功能，已创建的密码文章需保留受保护接口或由管理员迁移后再回滚。
