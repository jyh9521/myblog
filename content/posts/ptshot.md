最近 HDChina 复活了，我就想着从其他 PT 站转载几个种子混点上传量。

结果发现新站规要求发布的资源至少提供 3 张 PNG 格式的影片截图，这可难倒我了。

因为有些站点原先提供的截图并不是 PNG 格式，有些甚至不足 3 张。虽然我平时使用的 MPC 播放器也能截图，但只能自己拖动进度条、手动寻找合适的画面。对于我这种有选择困难症的人来说，光是决定截哪几张就够折腾的了。

于是开始寻找有没有能够自动截图的工具。

一番搜索之后，我发现了开源项目 [Mosaic](https://github.com/mosaicvideo/mosaic)。它可以自动从影片的不同时间点截取画面，还能生成带有影片信息和时间戳的预览拼图，完美符合我的需求。

截图的问题解决了，接下来就是上传图片。

PT 站发布资源通常需要提供图片外链，但我平时并没有固定使用的图床。又是一番搜索，最终找到了 [Pixhost](https://pixhost.to/)。

这个图床相当不错，免费、无需注册登录，直接上传就能获取图片外链，还支持通过 API 上传。

本以为事情到这里就结束了，结果又遇到了一个问题：Pixhost 对单张图片有 10 MB 的大小限制。

对于一些高分辨率影片，尤其是 4K 影片来说，原始 PNG 截图很容易超过这个限制。

当然，可以通过降低分辨率或者转换成 JPEG 来缩小体积，但既然站规要求 PNG，我也希望尽量保留原始画质。

于是又找到了第三个开源项目：[oxipng](https://github.com/oxipng/oxipng)。它能够对 PNG 图片进行无损优化，在不损失画质的前提下尽可能缩小文件体积。

折腾到这里，我突然想到，既然这三个工具正好可以解决三个连续的问题，为什么不干脆把它们整合起来呢？

于是就有了 PTShot。



---



## 项目介绍

PTShot 是一个面向 Windows 的影片截图及图床上传小工具，主要就是把自动截图、PNG 无损优化和 Pixhost 上传三个步骤整合到一起。

使用起来也很简单：添加影片，设置需要截取的图片数量和输出目录，点击开始，剩下的交给程序处理即可。

目前主要支持以下功能：

- 自动截图：调用 Mosaic CLI，从影片中均匀截取指定数量的原尺寸 PNG 图片，不需要再手动寻找截图位置。
- 预览拼图：可以生成带有时间戳和影片信息的拼图，也支持同时输出独立截图与拼图。
- 无损优化：当 PNG 超过 Pixhost 的大小限制时，自动调用 oxipng 尝试压缩，不会降低分辨率或进行有损转换。
- 自动上传：将符合大小限制的图片上传至 Pixhost，无需注册账号或配置 API Key。
- 一键复制：上传完成后可以直接复制全部高清图片直链或 BBCode，方便粘贴到 PT 站的发布页面。
- 任务记录：保留本地截图、上传结果及任务记录，支持重新打开历史任务并重试失败的图片。

需要说明的是，oxipng 毕竟是无损优化工具，并不能保证所有 PNG 都能压缩到 10 MB 以下。如果优化之后仍然超限，程序会保留原图并标记失败，不会偷偷降低画质。

另外，PTShot 上传的是 PNG 原图，获取的也是高清原图直链，而不是 Pixhost 的缩略图地址。

## 软件界面

![PTShot 主界面](/uploads/cms/8f17eec61b02451c8c60c9e3fe532c057fdfc45d836f205e98da881d9cfbdb40/PTShot.png)

界面使用了 Google 的 Material 3 Expressive 设计风格，支持浅色和深色主题。

整体没有设计得太复杂，主要就是截图、结果和设置三个页面。

毕竟只是一个小工具，我更希望能够打开软件、添加影片、点击开始，然后直接拿到能用的 BBCode，不需要进行太多额外操作。

## 下载与使用

项目地址： [GitHub - jyh9521/PTShot](https://github.com/jyh9521/PTShot)

软件下载： [PTShot Releases](https://github.com/jyh9521/PTShot/releases/tag/v0.2.0)

目前提供 Windows x64 便携版，下载 `PTShot-0.2.0-Windows-x64.zip`，完整解压后运行 `PTShot.exe` 即可。

打包版已经包含运行环境和所需的工具，不需要另外安装 Python 或 Node.js。

如果需要了解具体的配置方式、命令行用法或者实现细节，可以参考项目的 [README](https://github.com/jyh9521/PTShot#readme)。

## 最后

其实这也算不上什么特别复杂的项目，核心功能都是现成的开源工具提供的，我只是根据自己的实际需求，把它们串联起来，补上了图床上传、任务管理以及图形界面。

最初只是想转载几个种子混点上传，没想到从截图一路折腾到压缩、图床，最后干脆做成了一个独立工具。

不过这样也好，以后再发布资源，就不用手动找画面、截图、压缩、上传、复制链接了。

算是又解决了一个日常使用中的小麻烦。

最后感谢 [Mosaic](https://github.com/mosaicvideo/mosaic)、[oxipng](https://github.com/oxipng/oxipng) 等开源项目，以及提供免费图片托管服务的 [Pixhost](https://pixhost.to/)。

项目代码及相关说明已放在 GitHub，有需要的朋友可以自行下载使用。
